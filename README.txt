MasterPro WEB — Stage 18.4.6 Project Share

В компактной карточке проекта появилась кнопка «Поделиться».

Выпадающий список:
1. Ссылка для просмотра
2. Отправить проект в PDF

Ссылка для просмотра:
- создаётся отдельная read-only ссылка на весь выбранный проект;
- получателю не нужен аккаунт MasterPro;
- можно отправить через системное меню iPhone;
- можно скопировать;
- ссылку можно отозвать;
- показываются проект, заказчик, исполнители, выполненные объёмы,
  поступления и основные финансовые показатели;
- существующая отдельная ссылка мастеру сохранена.

PDF:
- на iPhone/PWA MasterPro пытается открыть системное меню «Поделиться»
  с готовым PDF-файлом;
- можно отправить PDF в Telegram, WhatsApp, Почту, AirDrop, Файлы и т. п.;
- если браузер не поддерживает передачу файлов через Web Share API,
  используется обычное сохранение PDF;
- используется существующий полный PDF-отчёт MasterPro.
