MasterPro WEB — Stage 18 Mobile Parity

Браузерная версия обновлена под актуальную мобильную архитектуру.

Сохранено:
- Supabase realtime/canonical sync;
- проекты;
- мастера и бригады;
- папки прайсов;
- Basic / Advanced;
- аватар;
- существующие данные пользователей.

Добавлено / приведено к мобильной версии:

1. Проекты и заказчики
- название проекта;
- заказчик: имя или компания;
- телефон;
- email;
- редактирование данных проекта;
- переименование проекта без потери данных.

2. Поступления от заказчика
- дата;
- сумма;
- комментарий;
- добавление;
- редактирование;
- удаление;
- итоговая сумма в проекте.

3. Advanced
- архив проектов;
- Активные / Архив;
- план / факт;
- процент готовности проекта;
- редактирование и удаление плановых позиций.

4. Выполненные работы
- статус записи:
  Запланировано / В работе / Выполнено / Принято;
- редактирование объёма;
- изменение дат;
- перенос записи между мастером и бригадой;
- удаление записи.

5. Прайсы
- убран обязательный "Тип возводимых конструкций";
- новые прайсы универсальные и сохраняются в custom;
- старые Потолки / Перегородки / Облицовка стен остаются совместимыми;
- при добавлении работы выбирается сразу Прайс → Раздел → Вид работы;
- тип конструкции пользователю больше не нужен.

6. Профиль
- текущий Basic / Advanced сохранён;
- настройки имени;
- смена пароля;
- RU / EN / System;
- аватар;
- на мобильном браузере для аватара доступна камера через системный выбор.

7. Интерфейс
- более тёмные placeholder во всех полях;
- новые поля и карточки адаптивны для мобильного браузера.

Синхронизация:
Новые поля хранятся внутри того же объекта проекта/profile, поэтому изменения
с мобильной версии и Web используют одну структуру Supabase.
