PWA-калькулятор для iPhone

Файлы:
- index.html — приложение
- manifest.webmanifest — настройки PWA
- service-worker.js — offline-кэш оболочки
- icons/ — иконки приложения

Важно:
1. PWA необходимо разместить на HTTPS-сайте. При открытии index.html как локального файла service worker и установка PWA не заработают.
2. После публикации откройте сайт на iPhone в Safari.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. После этого калькулятор запускается отдельным окном как приложение.

Supabase:
- Авторизация уже подключена.
- Сами проекты/мастера/выплаты пока остаются в localStorage текущего устройства, если вы ещё не переносили их в базу Supabase.
- Для полноценной синхронизации между iPhone/ПК нужно следующим этапом перенести рабочие данные в Supabase Database.

Offline:
- Интерфейс приложения кэшируется и сможет открыться без интернета после первого успешного запуска.
- Серверная авторизация Supabase и будущая синхронизация данных требуют интернет-соединение.
