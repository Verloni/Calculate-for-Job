MasterPro WEB — Stage 18.4.2 Invite Sync Fix

Исправлена пустая гостевая ссылка «Поделиться с мастером».

Причина:
старая Supabase-функция get_project_invite() читала legacy masterGroups.
А актуальные Web/iOS версии записывают выполненные объёмы в workEntries.
Поэтому ссылка была валидной, но мастер видел пустые работы.

ВАЖНО:
Одной замены index.html недостаточно.
Нужно один раз выполнить SQL-файл:
SUPABASE_INVITE_FIX_STAGE18_4_2.sql
в Supabase → SQL Editor → New query → Run.

После SQL:
- существующие ссылки НЕ нужно создавать заново;
- ссылка сразу читает актуальные данные проекта;
- мастер видит личные работы;
- мастер видит совместные работы бригад, в которых он состоит;
- учитываются налог мастера и его процент;
- отдельно считается заработок через бригады;
- выплаты и остаток показываются из актуальных данных.

GitHub Pages:
1. заменить index.html
2. заменить service-worker.js
3. выполнить SUPABASE_INVITE_FIX_STAGE18_4_2.sql в Supabase

После публикации полностью закрыть PWA и открыть снова.
